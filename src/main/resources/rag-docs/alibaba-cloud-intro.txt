阿里云百炼平台指南

阿里云百炼（Bailian）是一站式大模型服务平台，提供通义千问等模型的 API 访问。

如何使用百炼平台

1. 注册阿里云账号：访问 https://www.aliyun.com/
2. 开通百炼服务：进入 https://bailian.console.aliyun.com/
3. 创建 API Key：在"模型服务 → API Key 管理"中创建
4. 配置到项目：将 API Key 设置到环境变量 DASHSCOPE_API_KEY

计费方式

百炼平台采用按量付费（Pay-as-you-go）模式：

- qwen-turbo：约 ¥0.3/千Token（输入），¥0.6/千Token（输出）
- qwen-plus：约 ¥2/千Token（输入），¥6/千Token（输出）
- qwen-max：约 ¥20/千Token（输入），¥60/千Token（输出）
- text-embedding-v2：约 ¥0.5/千Token

新用户通常有免费试用额度（100万Token左右）。

可用模型一览

对话模型：
- qwen-turbo：速度最快，适合简单对话
- qwen-plus：性价比最高，推荐日常使用
- qwen-max：能力最强，适合复杂任务
- qwen-long：支持超长上下文（千万Token级）

视觉模型：
- qwen-vl-plus：图片理解，性价比推荐
- qwen-vl-max：最强视觉理解能力

Embedding 模型：
- text-embedding-v2：文本向量化，用于 RAG
