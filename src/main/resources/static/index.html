第9课

分层记忆

三层架构：滑动窗口（细节）+ 滚动摘要（压缩）+ 长期事实（跨会话）。可查看记忆内部状态。

POST /api/memory/chat
GET /api/memory/state
试试看

先告诉它你的身份，再问它记不记得，最后查看记忆状态

第10课

Agent 编排

显式 ReAct 循环 + 三重安全阀（迭代上限 / 死循环检测 / 格式纠错），返回结构化执行轨迹。

POST /api/agent/chat-trace
GET /api/agent/tools
试试看

轨迹会展示每一步的思考、调用的工具、工具返回的结果

第11课

评估体系

RAGAS 四指标 + 检索层 Recall@K/MRR/NDCG + 20 条金标准测试集 + 自动失败诊断。

GET /api/eval/dataset
POST /api/eval/smoke
POST /api/eval/run
试试看
